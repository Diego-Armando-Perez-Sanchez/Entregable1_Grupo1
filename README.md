# Entregable 1 — API REST de usuarios y mascotas

Proyecto académico de Electiva 1 - Backend.

## Objetivo

Construir una API REST con Node.js y Express para gestionar
usuarios y mascotas, con persistencia en archivos JSON y
carga de imágenes mediante Multer.

## Distribución del trabajo

- Persona 1: servidor, persistencia y configuración de archivos.
- Persona 2: usuarios y seguridad de contraseñas.
- Persona 3: mascotas y documentación.
